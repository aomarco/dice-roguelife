시작하기

이름과 세계만 고르면 됩니다. 나머지는 주사위가 정해요.

  • 죽으면 인생 결산 뒤 다른 세계의 다른 몸으로 회귀하고, 지난 삶의 능력 하나를 물려받는다.
  • 이 게임은 claude.ai 아티팩트 전용이다. 내 아티팩트로 띄우는 법은 README.
  • 입력: 말과 행동은 그대로 쓰고, 속마음이나 상황 설명만 *별표* 안에. 별표 안은 장면 속 누구도 듣지 못한다.

주사위 켜기 / 끄기

새 삶을 시작할 때 한 번 고릅니다. 시작하면 그 저장 내내 고정돼요.

켜면: 스릴

  • 체감 난이도 ↑, 스릴 ↑
  • 선택지 주사위: 위험한 행동과 확률이 붙은 선택지의 성패
  • 생활 주사위: 행동과 상관없이 가끔 오는 행운과 불운. 억울한 불운도 나올 수 있다
  • AI가 아니라 코드가 굴려서 한쪽으로 쏠리지 않는다
  • d100, 낮을수록 좋다. 성공 확률 60%면 60 이하가 성공

끄면: 자유

  • 주사위 없이 개연성으로 진행
  • 플레이어가 원하는 전개를 대체로 따라간다. 일부러 불리하게 비틀지 않는다
  • 선택지에 확률이 붙지 않는다. 선택지는 제안일 뿐
  • 내 입력이 그대로 받아들여지는 느낌의 롤플레이를 원하면 이쪽
  • 단, 없는 아이템이나 힘이 있다고 선언하면 허풍으로 처리된다 (켜든 끄든 같다)

/판정: 방금 판정의 근거 묻기

  • /판정은 주사위를 새로 굴리는 명령이 아니다. 방금 판정이 왜 그렇게 됐는지 묻는 명령이고, 게임 시간은 흐르지 않는다.
  • 이유가 규칙이나 기록과 어긋나면 AI가 인정하고 바로잡을 수 있다.
  • 판정이 이상하게 서술됐다면 먼저 이걸로 물어본다. 주사위 결과 자체는 코드가 정한 값이다.

내 설정으로 시작 (자유 설정)

주사위 대신 종족, 신분, 재능, 주변 인물을 직접 정할 수 있어요.

  • 이름: 내 캐릭터 이름. 성별은 남, 여, 기타.
  • 세계관, 등장인물: 인물 이름과 역할을 문장으로 적는다. 예: "소꿉친구 한서윤이 옆집에 산다. 겉으론 퉁명스럽지만 늘 나를 챙긴다."
  • 적은 내용은 유저 노트로 들어가 첫 장면부터 반영된다. 나중에 기억 탭에서 고칠 수 있다.
  • 플레이어 설정: 외형, 성격, 말버릇, 배경 서사. "다음 삶의 기본값으로 저장"도 가능.
  • 성좌: 무작위 / 있음 / 없음 (아래 성좌 항목 참고).

상태창과 칭호

상단 상태 바를 누르거나 /상태를 입력하면 열려요.

  • 기본값(자동)은 헌터물, VR MMO, 탑, 아카데미처럼 시스템이 있는 세계에서 각성 전엔 숫자를 숨기는 것. 그 외 세계는 처음부터 보인다.
  • ⚙ 설정 → 상태창 공개: 자동 / 항상 공개 / 모든 세계에서 각성 후 공개 / 숨김 (각성해도 숫자 없이 서사로만).
  • 칭호는 얻는 순간 자리가 남아 있으면 자동으로 켜진다. 효과는 칭호 옆에 표시된다.

성좌 (후원자) 옵션

나를 지켜보는 존재가 있는 삶인지 정합니다. 자유 설정에서 고를 수 있어요.

  • 성좌가 있는 삶은 채널이 처음엔 닫혀 있다. 각성이나 큰 사건으로 열린다.
  • 열리기 전에 /성좌를 치면 "아직 당신을 보지 않아요" 안내가 뜨고, 성좌가 없는 삶이면 "이 세계에는 성좌가 없어요"가 뜬다.
  • 주사위로 시작하면 세계별 확률로 정해진다. 헌터물과 탑은 성좌가 흔하다.
  • ADMIN 말투는 ⚙ 설정의 ADMIN 페르소나로 바꾼다.

이미지 태깅 시스템

초상화와 배경을 올리면 앱이 장면에 맞춰 알아서 붙여요. 이미지가 없어도 텍스트로 플레이할 수 있어요.

앱이 그림을 고르는 원리

인물

  • 세트 = 한 사람. 표정(emotion)은 그 세트 안에서 장면에 맞는 얼굴을 고른다.
  • AI가 인물을 설명한다: 성별, 역할, 비중, 외형 단어, 소속.
  • 코드가 세트의 태그, 역할, 분위기와 단어 단위로 비교해 점수를 매긴다.
  • 정체 태그 faction:은빛기사단이 맞으면 크게 가산된다.
  • 세계(worlds)와 성별이 맞는 세트만 후보. 많은 세트에 공통인 단어(hair, smile)는 무게 0.
  • 비중(tier)이 비슷하면 가산: 엑스트라 / 조연 / 주요.
  • 한 번 정해진 얼굴은 그 삶 내내 같은 사람에게 유지된다.

배경

  • AI가 장소를 영어 단어로 설명한다 (종류가 먼저: station, locker).
  • 코드가 이 세계의 배경 중에서 검색한다. 종류 단어가 전부 있어야 한다.
  • 시간대(day, night, sunset)로 변형을 고른다.
  • 애매하면 틀린 그림보다 그림 없음을 택한다.
  • 가본 곳은 같은 그림을 다시 쓴다.

파일 이름 규칙

종류이름예
캐릭터{세트}_{표정}.pngfemale1_smile.png
같은 표정 둘째 장{세트}_{표정}_2.pngfemale1_smile_2.png (smile2도 지금은 인식한다)
다른 의상{세트}_{표정}_{의상}.pngfemale1_smile_armor.png
배경bg_{장소}_{시간}.pngbg_tavern_night.png, bg_castle-gate_day.png
그림자shadow_{male|female}_{표정}.pngshadow_male_neutral.png
게임 마스터admin_{표정}.pngadmin_smirk.png
연출 (주사위)dice.png dice_success.png dice_fail.png fx_*.png대성공, 대실패 때만 뜬다

표정은 neutral smile joy anger sadness surprise smirk shy fear serious crying determined 중 하나. 이름이 규칙에 안 맞으면 올릴 때 물어본다. 같은 파일(내용이나 이름이 같음)을 다시 올리면 건너뛴다.

tags.json

  • 이미지 탭 → tags.json 가져오기로 세트 정보와 태그를 한 번에 넣는다.
  • sets: gender(male/female/other), worlds, role, vibe, look, tier(extra/minor/major), tags, name, aliases
  • images: 파일 이름별 emotion, tags, worlds
  • backgrounds: 파일 이름별 place, time, mood, tags, worlds
  • 태그: 묘사는 영어 소문자(3~6개), 고유명사만 원래 언어. 정체 태그는 key:value (예: faction:사천당가).

팩 내보내기

  • 팩 내보내기: 이미지를 올릴 때 쓰는 이름으로 zip에 담고 tags.json까지 넣어 내려받는다. 다른 아티팩트나 친구에게 그대로 옮길 수 있다.
  • 태그만 내보내기: 이미지 없이 tags.json만 내려받는다.
  • 이미지는 아티팩트마다 따로 저장되므로, 새 링크로 옮길 때 이 팩을 다시 올리면 된다.

Claude에게 정리 맡기기 (프롬프트)

이미지 폴더를 Claude(Cowork 등)에 주고 아래 프롬프트를 붙여 넣으면 이름 짓기, 세트 묶기, tags.json까지 만들어 준다. 먼저 계획(PLAN.md)을 보여 주고 확인을 받는다.

프롬프트 펼치기 / 복사 
Organize and tag the images in this folder for the game "Dice Roguelife" (주사위가 정한 인생).

Goal: group images of the same character into "sets", name every file with the game's
convention, and write a tags.json the app can import (이미지 tab -> import).

Rules
1. Do NOT modify or delete the originals. Copy everything into ./organized/.
2. First look at every image and write a plan to ./organized/PLAN.md
   (old filename -> new filename, plus tags). Show me a summary and wait for my OK
   before copying or renaming anything.
3. If ./existing_filenames.txt exists (optional), it lists files already in my game library.
   New names must never collide with it; continue set numbers after the highest one there.
4. Also write ./organized/MAPPING.csv with two columns: original_filename,new_filename.

Characters (portraits or sprites of a person or creature)
- Group images of the same character (same face, hair, outfit design) into one set.
- Set names: female1, female2, male1, male2, ... (creature1 for non-humans).
  Letters, digits and hyphens only.
- Filename: {set}_{emotion}.{ext}, e.g. female1_smile.png
- Emotion must be one of: neutral, smile, joy, anger, sadness, surprise, smirk,
  shy, fear, serious, crying, determined. Pick the closest one.
- Two images with the same emotion in a set: add a number after an underscore,
  female1_smile_2.png (never female1_smile2.png; the app would not recognize the emotion).
- Alternate outfit: add it after the emotion, female1_smile_armor.png
- If a name is written in the image, read it exactly. Put the in-game Korean name in
  "name" and the original spelling in "aliases". If unreadable, do not guess; flag it.

Backgrounds (scenes without a main character)
- Filename: bg_{place}_{time}.{ext}, e.g. bg_tavern_night.png, bg_castle-gate_day.png
- place: lowercase English, hyphens between words. time: day, sunset, night or indoor.
- Two backgrounds with the same place and time: add a number, bg_alley_day2.png
- A specific landmark (e.g. a school auditorium) goes in tags, not in a new field.

Effects (dice or effect art that is neither a character nor a scene)
- Name them dice.png, dice_success.png, dice_fail.png, or fx_{what}.png. No tags needed.

Skip files that are already named as system assets: shadow_*, admin_*, dice*, fx*.

Worlds (for "worlds", 0 to 3 that clearly fit; empty array if it fits anywhere):
hunter, apoc, academy, tower, vrmmo, fantasy, rofan, murim, palace, cyber, monster

Tags
- Descriptive tags: lowercase English, 3 to 6 (hair, outfit, props, mood; for backgrounds:
  place, time of day, weather, mood).
- Identity tags (optional): key:value, key in English, value is a proper noun kept in its
  original language, e.g. faction:사천당가
- Only proper nouns stay in their own language; everything else is English.

tags.json (keyed by the NEW filenames)
{
  "sets": {
    "female1": {"gender": "female", "worlds": ["fantasy"], "role": "knight",
                "vibe": "stern, loyal", "look": "silver hair, blue armor",
                "tier": "major", "tags": ["silver hair", "knight"]}
  },
  "images": {
    "female1_smile.png": {"emotion": "smile", "tags": ["smile", "armor"], "worlds": ["fantasy"]}
  },
  "backgrounds": {
    "bg_tavern_night.png": {"place": "tavern", "time": "night", "mood": ["lively", "warm"],
                            "tags": ["wooden tables", "lanterns"], "worlds": ["fantasy"]}
  }
}
- gender: male, female, or other (for non-humans).
- tier: extra, minor or major (how prominent the face is).
- Keep role, vibe and look short; the app joins them into one line of at most 120 characters.
- "name" and "aliases" only for sets with a readable name in the image.

Also
- If one image contains several characters or a grid of expressions, flag it in PLAN.md
  instead of guessing.
- Flag duplicates or near-duplicates.
- At the end, print a short summary: number of sets, images per set, backgrounds per world,
  and everything flagged.

그림자 (shadow)

  • 무엇: 얼굴 없는 실루엣 세트. 여러 배경 인물이 공유한다.
  • 어디에: 엑스트라(지나가는 사람)에게 공유 실루엣이 붙는다. 정체를 숨긴 화자도 실루엣으로 나온다. 조연, 주요 인물에게는 쓰지 않는다.
  • 만들기 1: 파일 이름을 shadow_male_neutral.png, shadow_female_2.png처럼. shadow, generic, silhouette 접두사가 통하고, 성별별로 shadow_male, shadow_female, shadow_other 세트가 자동으로 생긴다.
  • 만들기 2: 아무 세트 카드의 그림자를 체크. 그 세트는 실루엣 전용이 되어 실제 얼굴로는 쓰이지 않는다. shadow_ 이름의 세트와 고정 이름이 있는 세트는 체크가 잠긴다.
  • 제외: 체크하면 그 세트는 자동으로 누구에게도 배정되지 않는다.
  • 왜 올리나: 엑스트라용 얼굴이 떨어지면 "엑스트라에게 줄 얼굴이 다 떨어졌어요. 그림자(shadow_)나 엑스트라 이미지를 더 올리면 다시 붙어요" 안내가 뜬다. 그림자를 몇 장 올려 두면 해결된다.

잘못 등록된 이미지 고치기

  • 종류, 세트, 표정이 틀렸다 → 카드의 드롭다운으로 바꾼다.
  • 태그가 틀렸다 → 태그 칸에서 고치거나 ✕로 지운다. 영어가 아닌 태그는 태그 영어로로 한 번에 바꾼다.
  • 소속(문파, 가문, 회사)을 태그로 → 소속 태그 뽑기. 적용 전에 목록을 보여 준다.
  • 분류를 AI에게 다시 → 자동 분류.
  • 같은 그림이 두 번 올라갔다 → 중복 정리 (먼저 올린 쪽만 남는다).
  • 그림 바꾸기: 같은 이름이나 같은 내용의 파일은 건너뛰므로 그냥 다시 올리면 안 된다. 카드에서 삭제한 뒤 새 그림을 올린다 (같은 파일 이름도 삭제 후엔 가능).

이미지 구하는 법

  • AI로 만들기: NovelAI처럼 애니 스타일 생성 서비스를 추천한다. 사이트 안내에 따르면 생성한 이미지는 상업적 사용에도 제한이 없다고 한다. 쓰기 전에 약관을 직접 확인할 것.

개인 사용만
  • 혼자 플레이할 때, 이미 갖고 있던 이미지를 쓰는 사람도 있다. 예: 다른 챗 서비스에서 저장해 둔 이미지, 구글 이미지 검색에서 찾은 이미지.
  • 저작권은 원 권리자에게 있다. 내 컴퓨터, 내 아티팩트에서 개인적으로만 쓴다.
  • 절대 공유, 재배포하지 않는다. 팩, PR, 이슈에 넣지 않는다. 기여는 저작권이 깨끗한 것만 받는다.
  • 이 프로젝트는 이런 사용을 권장하지 않는다.

알려진 문제

1. 같은 사람이 이름만 바뀌어 따로 생긴다

AI가 가끔 대성통신 사장, 대성통신 주인처럼 같은 인물을 다른 이름표로 따로 만든다. 합치기로 해결한다.

예방: 새 게임의 세계관, 등장인물 칸에 이름을 정해 두고 한 이름으로만 부르게 적어 둔다 (위 "내 설정으로 시작").

2. 판정이 이상하게 서술된다

가끔 주사위 결과와 서술이 어긋나 이야기가 어색해질 수 있다. 이럴 땐 /판정으로 근거를 묻는다. 규칙과 어긋났다면 AI가 바로잡을 수 있다. 계속 거슬리면 주사위를 끄고 시작하는 방법도 있다.

3. 저장 공간이 가득 찼어요

  • 저장 탭에서 오래된 저장이나 분기를 이야기 내보내기로 파일에 남긴 뒤 삭제하면 공간이 생긴다.

그 밖의 제약

  • claude.ai 아티팩트에서만 돌아간다. 일반 웹사이트로 열면 AI를 부를 수 없다.
  • 저장은 그 아티팩트에 묶인다. 업데이트는 항상 같은 링크에 덮어쓰기.
  • 이미지는 아티팩트마다 따로다. 새 링크로 옮기면 다시 올리거나 팩 내보내기 파일을 쓴다.
  • 이미지 업로드는 앱 소유자만 할 수 있다. 게시된 링크에서 연다.
  • 사용량 한도는 Anthropic이 정한다. 자주 걸리면 최근 기억 분량을 줄인다.
